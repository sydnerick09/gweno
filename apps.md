# Application Rules

## Subscription Plans
The application supports:
- Basic
- Premium
- Premium Pro
- Exclusive Plan

All valid plans must be recognized consistently throughout the application.

## Exclusive Plan
The Exclusive Plan already exists in the application's subscription or navigation system.

When working with the Exclusive Plan:
- Do not create a duplicate plan configuration.
- Find and reuse the existing Exclusive Plan configuration.
- Include it in all relevant plan selectors and validation systems.
- The Admin Panel Change Plan feature must support assigning the Exclusive Plan.
- Users assigned the Exclusive Plan must retain the plan after refreshing.
- The user's dashboard and permissions must immediately recognize the new plan.

## Plan Consistency Rule
A plan available to users must also be recognized by:
- Admin Panel
- Change Plan controls
- User profile
- Dashboard
- Access validation
- Task restrictions
- Subscription status
- Storage logic
