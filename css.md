# CSS and Design Rules

## Preserve Existing Design
Do not redesign the application unless explicitly requested.

New elements must match the existing:
- Colors
- Typography
- Spacing
- Buttons
- Cards
- Forms
- Modals
- Responsive behavior

## Admin Panel
Changes to the Admin Panel should integrate with the current design.

Do not introduce unnecessary new styles if an existing class or component can be reused.

## Responsive Rules
All changes must work on:
- Small mobile screens
- Tablets
- Desktop

Prevent:
- Horizontal overflow
- Overlapping elements
- Hidden controls
- Unclickable buttons
- Broken dropdowns or modals

## CSS Changes
- Make minimal CSS changes.
- Reuse existing CSS variables when available.
- Avoid global selectors that can affect unrelated pages.
- Keep styles organized.
- Do not add duplicate styles for existing components.
