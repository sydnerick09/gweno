# Code and Development Standards

- Follow the existing project architecture.
- Follow the existing programming language and framework.
- Keep code simple and maintainable.
- Prefer modifying existing code over creating unnecessary new files.
- Reuse existing utilities and functions.
- Do not duplicate business logic.

## Before Writing New Code
1. Search for an existing implementation.
2. Identify related functions and components.
3. Reuse existing patterns.
4. Make targeted changes only.

## Avoid
- Unnecessary dependencies
- Duplicate functions
- Duplicate plan configurations
- Large rewrites for small changes
- Unrelated refactoring
- Breaking changes

## Completion
Before finishing:
- Check for syntax errors.
- Check affected features.
- Verify persistence.
- Verify desktop and mobile behavior.
- Ensure existing functionality remains unchanged.
